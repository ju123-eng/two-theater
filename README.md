# 두 사람의 상영관

두 주연의 이름과 장르를 고르면, 그 둘이 주인공인 영화가 상영되는 웹 시뮬레이션입니다.

▶ 플레이: https://ju123-eng.github.io/two-theater/

## 안내

- 이 영화의 인물과 사건은 모두 가상입니다.
- 실존 인물의 이름은 넣지 말아 주세요.
- 입력한 이름은 어디에도 전송·수집되지 않습니다. 모든 계산은 플레이하는 사람의 브라우저 안에서만 이루어집니다.
- 결과 이미지는 자유롭게 공유해 주세요.
